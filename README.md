### 👋 About me

Senior Full-Stack Developer & AI Engineer from Argentina 🇦🇷, with 7+ years shipping production software alongside international teams. I came up through the **software craftsmanship** movement — clean code, solid architecture, XP practices and engineering rigor — and today I'm focused on bringing that same discipline to building **with** AI: RAG pipelines, agent architectures and observable LLM systems.

I work best in TypeScript-heavy stacks, I think in trade-offs rather than hype, and I like turning vague requirements into specs an engineer (or an agent) can actually execute.

---

### 🚀 What I'm building (Focus 2026)

- 🧠 **[VDP](https://github.com/ldamoredev/vdp)** — a personal AI assistant platform: a pnpm + Turborepo monorepo with a Next.js 15 web app, a Fastify 5 API, Postgres + pgvector and the Anthropic SDK, instrumented end-to-end with Langfuse + OpenTelemetry.
- 🤖 Going deeper on **agent architecture, RAG and production LLM observability** — and on using AI to raise engineering rigor, not replace it.
- 🛡️ Maintaining an **operational cybersecurity knowledge vault** — runnable payloads, named CVEs and testing workflows instead of shallow notes.
